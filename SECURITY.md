# Security reporting

Report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/oliverdougherC/Lyra/security/advisories/new).
Private reporting is enabled for this repository. Do not open a public issue containing keys,
private coursework, student databases, exploitable details, or unredacted diagnostic archives.

Include the app version/build, macOS version, architecture, reproduction steps, impact, and a
minimal synthetic example. Keep original student files and credentials out of the report.
There is no supported public beta yet; release support scope will accompany published releases.

GitHub Issues is tester intake. Confirmed engineering work is tracked in Linear.
