# Writer Roadmap Archive

Status: archived.

This file preserves the plan that led to the current draft workspace. It is not a live checklist
and should not be read as future work. The implementation record lives in
[docs/writer-overhaul.md](writer-overhaul.md),
[docs/integration-handoff.md](integration-handoff.md), and
[docs/phase-4-writer-integration.md](phase-4-writer-integration.md).

## Current snapshot

The writer workspace now exists and includes:

- a draft brief
- a plan panel
- a source ledger
- writer chat
- comments and revision flows
- suggestions and review
- export
- optional Exa-backed web research support

The main open work is reliability, not feature invention. The app still needs more error handling,
stronger recovery, and more regression coverage around the writer flows.

## Historical plan

The original roadmap was split into six steps:

- W1 - truthful foundations
- W2 - the plan as an artifact
- W3 - research and citations
- W4 - the convergence loop
- W5 - review that feels good
- W6 - the parallel door

Those labels are preserved here so older handoff notes still make sense. They are historical
milestones, not a future checklist.

## Use this file for

- understanding why the writer workspace is shaped the way it is
- tracing older handoff references
- checking what was promised before the writer overhaul landed

## Do not use this file for

- deciding what to build next
- claiming that the writer roadmap is still pending
- replacing the current feature roadmap or the implementation records
